# Blog CRUD API

A simple **Blog Management REST API** built using **Node.js, Express.js, and MongoDB with Mongoose**.

This project was created to understand and practice basic **CRUD operations** — Create, Read, Update, and Delete — using a backend application.

---

## 🚀 Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- Thunder Client / Postman
- dotenv
- Nodemon

---

## 📌 Features

- Create a new blog
- Get all blogs
- Get a single blog by ID
- Update a blog
- Delete a blog
- Store blog data in MongoDB
- Basic error handling
- Structured REST API architecture
